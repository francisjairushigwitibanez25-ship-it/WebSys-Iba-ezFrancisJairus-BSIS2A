## Weekly Summary

### Week 1 - HTML Fundamentals
Created the basic structure of web pages using HTML elements, headings, paragraphs, links, images, and lists.

### Week 2 - Semantic & Multimedia
Used semantic HTML elements to organize web content and added multimedia elements such as images, audio, and video.

### Week 3 - CSS Basics
Applied CSS styles, colors, fonts, spacing, borders, and layouts to improve the appearance of web pages.

### Week 4 - JavaScript Basics and DOM Manipulation
Used JavaScript to make web pages interactive by changing HTML content, updating styles, handling events, and responding to user actions.

### Week 5 - JavaScript Functions and Bootstrap
Practiced JavaScript functions and used Bootstrap components to create responsive layouts and interactive user interfaces.

### Week 6 - API & Client Storage
Created activities involving user preferences, weather information, a GitHub username finder, and OpenStreetMap. Used browser storage to save user settings and APIs to display information dynamically.

### Week 7 - MiniFullStackStarter
Developed the backend of a web application using Node.js, Express, and MongoDB. Created API routes, connected the database, and practiced handling user information through forms.
